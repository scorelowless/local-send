# Flutter app for sending and receiving messages through LAN

The app was written for a Flutter course and allows for sharing messages over a local area network (LAN).

The inspiration for the app came from the need to sometimes share a photo, a hyperlink or an ordinary message from one device to another without the need to use online communication services nor physical cable.

The app was designed for Android and Linux devices and thus was tested mostly on them. The Windows support is not guaranteed, while the iOS is not supported.

## Features
- Send and receive messages over LAN
- Share both text messages and files
- Adjustable color theme.
- Easy detection of nearby devices on the same network.
- Easy to use interface.
- Add devices to favorites and change their display names.
- Localization support for English and Polish languages (there is also a German language to choose, but it was used as a test and is not actually German).

## AI disclosure
The project was heavily developed with the help of AI tools, including ChatGPT and GitHub Copilot.
The idea behind the project and the functionalities were created by the author.
The author also manually fixed the networking layer, because the AI tools were unreliable in this matter.
Vast parts of the code and documentation comments were generated by AI tools.
The author manually fixed the bugs stemming from the AI-generated code.

As the project was developed with more extensive use of AI tools than the author would like to (due to time constraints), the author does not guarantee that the code is bugless.
The project is provided in the current form and any possible further developments would happen as a separate project, less dependent on AI tools.
